# Scrap Idle

Инкрементальная веб-игра про мусор. Всё работает само: покупайте улучшения и растите свалку.

Играть: https://isedis.github.io/scrap-idle/

Концепт и этапы: [docs/CONCEPT.md](docs/CONCEPT.md).

## Запуск

```bash
npm install
npm run dev      # дев-сервер, открывается и с телефона в той же сети
npm test         # тесты (vitest)
npm run build    # проверка типов и сборка в dist/
```

Пуш в `main` собирает игру и выкладывает её на GitHub Pages.
