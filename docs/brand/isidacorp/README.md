# Isidacorp — брендбук v1.0

Основой служит выбранный первый вариант: ASCII-лицо, красный ореол и ASCII-название ISIDACORP.

- `Isidacorp-Brandbook-v1.pdf` — 12 страниц рекомендаций и примеров.
- `index.html` — автономная версия с встроенными изображением и шрифтом, открывается без интернета.
- `assets/isidacorp-logo.png` — отдельный экспорт логотипа на чёрном фоне, 1254×1254.
- `brand-tokens.css` и `brand-tokens.json` — параметры для цифровых макетов.
- `assets/` — шрифты JetBrains Mono для латиницы и кириллицы и их лицензия SIL OFL.

В PNG есть внешние чёрные поля. Охранное поле и минимальный размер измеряются по видимой композиции. Не перерисовывать логотип автоматически и не заменять ASCII-название обычным шрифтом.

Документ предлагает систему применения выбранного знака. Примеры сайта, слогана и заставки демонстрационные. Полная векторизация, прозрачный оригинал, favicon и видео в этот комплект не входят.

Игровой репозиторий и опубликованный сайт Scrap Idle не изменялись.
