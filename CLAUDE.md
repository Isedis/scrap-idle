# Scrap Idle

- Концепт и этапы: `docs/CONCEPT.md`. Новые механики сверяй с ним.
- Игровая логика в `src/game/` без DOM, интерфейс в `src/ui/`. Логику покрывают тесты в `tests/`.
- Все игровые числа — `Decimal` из `src/game/num.ts` (break_eternity.js), показ только через `format()`.
- Тексты интерфейса на русском.
- Телефон в приоритете: кнопки не меньше 44px, без горизонтальной прокрутки.
- Меняешь формат сохранения — повышай версию в `src/game/save.ts` и добавляй миграцию со старой версии и тест на неё.
- Перед пушем: `npm test` и `npm run build`.
