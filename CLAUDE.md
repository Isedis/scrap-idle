# Scrap Idle

Idle-хоррор про мусор: свалка → переработка → сортировка → город → «Под ямой». Vite + TypeScript, без фреймворка.

## Правила

- Концепт и этапы: `docs/CONCEPT.md`. Новые механики сверяй с ним и отмечай там сделанное.
- Сюжет и тон: `docs/STORY.md`. Новые события и тексты сверяй с ним и дописывай туда главы.
- Игровая логика в `src/game/` без DOM, интерфейс в `src/ui/`. Логику покрывают тесты в `tests/`.
- Все игровые числа — `Decimal` из `src/game/num.ts` (break_eternity.js, `D()`), показ только через `format()`.
- Тексты интерфейса на русском. Комментарии и сообщения коммитов — на английском, в стиле соседнего кода.
- Телефон в приоритете: кнопки не меньше 44px, без горизонтальной прокрутки.
- Меняешь формат сохранения — повышай версию в `src/game/save.ts` и добавляй миграцию со старой версии и тест на неё.
- Слои перерождения описаны в `src/game/layers.ts`; новый слой добавляется туда же, его состояние хранится в сохранении под `layers.<id>` (город — `layers.city`).

## Проверка и темп

- Перед пушем: `npm test` и `npm run build`. Гейтить коммит так: `npm test > /dev/null && npm run build && git commit …` — `grep` по выводу прячет падения.
- Темп проверяет бот (`src/game/bot.ts`, `tests/pacing.test.ts`). В `npm test` он смотрит первые полтора часа.
  - `PACE=1 npx vitest run tests/pacing.test.ts` — 3 и 6 часов, печатает хронологию открытий.
  - `PACE_SORT=1` — 6 часов с сортировкой (около 3.5 минуты).
  - `PACE_CITY=1` — 4 часа, город должен открыться между 2 и 4 часами (около 2 минут).
  - Меняешь цены или доходы — прогоняй соответствующие.

## Деплой

- Рабочая ветка `claude/infinite`. Деплой разрешён: `git push -u origin claude/infinite && git push origin claude/infinite:main`.
- GitHub Pages собирает `main` (`.github/workflows/deploy.yml`: `npm ci`, тест, сборка). Сайт: https://isedis.github.io/scrap-idle/
- Выкатилось ли — смотри `https://isedis.github.io/scrap-idle/version.json`: там короткий хэш коммита. Опрашивай в фоне каждые 15 с.
- Игрок обновляет игру на iPhone через Настройки → «Обновить».

## Как работать с автором

- Отвечай по-русски, коротко; в конце — что изменилось для игрока и что выкатилось.
- Большие механики сначала обсуди концептом или уточняющими вопросами (AskUserQuestion), мелкие правки делай сразу.
- Перед визуальными изменениями и после них — скриншоты в мобильном вьюпорте 390×844.
- Автор не любит: полноэкранные оверлеи поверх игры (хоррор показывать в кадре камер), людей-монстров (всё — из мусора), спам уведомлений, интерфейс «сеткой кнопок».
- Хоррор должен работать и без звука: каждому звуковому пугалу — визуальная пара.

## Скриншоты

- `npx vite preview --port 4181` после `npm run build`, адрес `http://localhost:4181/scrap-idle/`. Playwright уже стоит (`require('playwright')`, `NODE_PATH=$(npm root -g)`).
- Сохранение подкладывать через `addInitScript` с флагом в `sessionStorage`, иначе `pagehide` перезапишет его. Ключ — `scrap-idle-save`; ставь `lastTick` в будущее, чтобы не было экрана «пока вас не было»; `scrap-idle-intro-sorting` и `scrap-idle-intro-noise` = `1` убирают вступления.
- Тосты перехватывают клики — прячь `.toast` перед кликами.

## Карта кода

- `src/game/state.ts` — состояние, `advance()` (тик и офлайн), покупки, перерождения, `reform()`.
- `threat.ts` — угроза свалки и прожектор; `hearing.ts` — «Слух» (шум цеха, проход, проверка у двери).
- `layers.ts` — переработка и её дерево; `sorting.ts` — линия, стол осмотра, рецепты; `city.ts` — Глухово: план (Вороной), кварталы, туман, яма, письма, эффекты.
- `scripts.ts` — автоматика; `story.ts` — записи камер и дела; `save.ts` — формат и миграции; `away.ts` — отчёт об отсутствии.
- `src/ui/app.ts` — сборка экрана, вкладки, тосты, уведомления; `*Cam.ts` — камеры на канвасе; `*Panel.ts` — вкладки; `sound.ts`, `music.ts`, `huntScore.ts` — звук (WebAudio, без файлов).
- Не сохраняемые настройки интерфейса лежат в `localStorage` с префиксом `scrap-idle-` (свёрнутые ветки, объявленное, громкость).
